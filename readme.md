# 🧹 ESLint + Prettier + Husky Starter

A minimal setup for consistent and clean code formatting using ESLint, Prettier, and Husky.

## 📦 What's included

- [ESLint](https://eslint.org/) 9+ (Flat config)
- [Prettier](https://prettier.io/)
- [Husky](https://github.com/typicode/husky)
- [.editorconfig](https://editorconfig.org/)

## 🚀 Supported stacks

Different configurations are available in separate branches:

- **`main`** - This README and basic setup
- **`html-vanilla`** - HTML / Markdown / CSS / Vanilla JavaScript
- **`react`** - React
- **`react-router`** - React Router 7 (framework)
- **`nextjs`** - Next.js

## 🛠 Installation

Choose your stack and switch to the corresponding branch:

```bash
# For HTML/Vanilla JS
git checkout html-vanilla

# For React
git checkout react

# For Next.js
git checkout nextjs

# For React Router 7 (framework)
git checkout react-router
```

Then install dependencies:

```bash
npm install
```
